# 딸깍 다마고치

작업표시줄 위에서 함께 지내는 작은 친구입니다.

## 다운로드

**[Windows 64비트용 최신 버전 다운로드](https://github.com/jooingong1/ddalkkak-tamagotchi-releases/releases/latest/download/ddalkkak-tamagotchi-Windows-x64.zip)**

[버전별 변경 사항](https://github.com/jooingong1/ddalkkak-tamagotchi-releases/releases)

**v0.1.3부터 게임 안에서 업데이트할 수 있습니다.** 집 창 위 ‘업데이트’ → ‘업데이트하고 다시 시작’을 누르면 다운로드·압축 해제·파일 교체·재실행을 자동 처리합니다. v0.1.2 이하는 이 버전을 한 번 직접 설치해야 합니다.

v0.1.2부터 공용 채팅 서버에 기본 연결합니다. 서버 주소를 입력하지 않고 새 방을 만들거나 초대 코드로 입장할 수 있습니다. 게임이 실행 중이면 시작 시 한 번, 이후 5분 간격으로 서버 상태를 확인합니다.

GitHub 로그인이나 Node.js 설치 없이 받을 수 있습니다.

## v0.1.6 변경 사항

- 패치 노트에서 v0.1.5·v0.1.4 내용도 버전별로 함께 표시
- 새 버전 안내창과 알림 영역 알림, 클릭하면 업데이트 화면 열기
- 실행 시 및 실행 중 30분마다 확인, 같은 버전 알림은 실행 중 1회

v0.1.6을 한 번 받으면 이후 새 버전에 보완된 알림을 사용할 수 있습니다. 설치는 직접 선택합니다.

## v0.1.4 변경 사항

- 실행 시 새 업데이트 알림·최초 패치 노트 표시

v0.1.3 사용자는 게임의 업데이트 버튼으로 받을 수 있습니다. v0.1.4부터 실행 시 새 버전을 자동 확인합니다. 기억한 채팅방은 재실행 후 방 목록의 재입장으로 연결합니다. 여러 방 접속 시 보상은 한 번만 지급되며 작업표시줄 친구는 선택한 방 기준입니다.

## 실행하기

1. ZIP 파일을 내려받아 압축을 완전히 풀어 주세요.
2. 압축을 푼 폴더의 `딸깍다마고치.exe`를 실행하세요. EXE 옆의 다른 파일과 폴더도 필요합니다.
3. 캐릭터와 방 분위기를 선택하면 새 알로 시작합니다. 시작 선물은 동전 300개와 방 분위기에 맞는 인형입니다.

다른 프로그램에서 타이핑 4,000회를 채우면 부화합니다. 이후 약 3일이면 성체가 됩니다. 입력한 글자는 저장하지 않고 횟수만 셉니다.

집 창을 닫거나 최소화하면 작업표시줄 위로 산책합니다. 알림 영역의 알 아이콘을 누르면 집으로 돌아오며, 우클릭 메뉴의 **끝내기**로 완전히 종료합니다.

## 친구방과 채팅

집 창의 **친구·채팅**에서 초대방을 만들거나 초대 코드로 입장할 수 있습니다. 방장 포함 최대 12명이 함께할 수 있습니다.

기본 서버는 `https://ddalkkak-chat.onrender.com`입니다. 서로 다른 집·네트워크에서도 같은 초대 코드로 입장할 수 있습니다. 다른 서버를 사용하려면 ‘서버 주소 설정’을 펼치세요.

무료 서버가 절전 상태이면 처음 연결에 최대 90초 걸릴 수 있습니다. 게임을 켜 두면 5분 간격의 상태 확인과 접속 중 통신으로 사용 상태를 유지합니다. 게임을 완전히 종료하거나 PC를 끄거나 절전시키면 해당 PC의 확인은 멈춥니다. 무료 사용 시간·트래픽 한도와 서비스 점검은 계속 적용됩니다. 서버가 재시작되면 방·초대 코드·대화는 사라져 새 방을 만들어야 합니다.

방에 접속한 동안에는 동전·재료를 20~45초의 랜덤 간격으로 자동 지급합니다. 타이핑 보상도 함께 받으며, 두 보상 모두 바닥에 떨어지지 않고 바로 보유 수량에 추가됩니다. 연결 해제·퇴장·앱 종료 후에는 시간 보상이 쌓이지 않습니다.

## 업데이트와 저장

v0.1.3 이상에서는 집 창 위 ‘업데이트’로 새 버전을 확인하고 설치할 수 있습니다. 파일을 모두 준비한 뒤 자동으로 종료·교체·재실행하며, 이전 게임 파일은 백업으로 남습니다. 다운로드·검증·준비에 실패하면 현재 게임을 계속 사용할 수 있습니다.

처음 설치하거나 수동으로 업데이트할 때는 게임을 완전히 종료한 다음 최신 ZIP을 새 폴더에 풀어 실행하세요. ZIP 안의 ‘딸깍다마고치’ 폴더 이름을 그대로 사용하세요. 진행은 게임 폴더와 별도로 `%APPDATA%\딸깍다마고치`에 저장되므로 같은 Windows 사용자 계정에서는 이어서 플레이합니다.

다른 PC로 옮길 때는 양쪽 게임을 모두 종료하고 `save.json`과 `save.json.bak`도 새 PC의 같은 저장 폴더에 복사하세요. 대상 PC에 저장이 있으면 먼저 백업하세요. 베타판의 원본 저장은 `%APPDATA%\딸깍다마고치-베타`에 있습니다.

공개 배포판에는 제작자의 개인 저장, 시험 패널, 캐릭터 시뮬레이션이 포함되지 않습니다. 먹구름 효과는 아직 미적용 시안입니다.
