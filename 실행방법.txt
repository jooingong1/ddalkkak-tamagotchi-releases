딸깍 다마고치 실행 방법 (Windows 64비트)

1. 받은 ZIP 파일을 우클릭해서 '압축 풀기'를 선택하세요.
2. 압축을 푼 폴더 안의 '딸깍다마고치.exe'를 실행하세요.

Node.js나 Electron을 따로 설치할 필요가 없습니다.
EXE만 따로 옮기지 말고 resources, locales, DLL 등 모든 파일을 같은 폴더에 두세요.
친구에게 공유할 때는 ZIP 전체를 보내면 됩니다.

다른 프로그램에서 타이핑 4,000회를 채우면 알이 부화합니다. 글자는 저장하지 않고 횟수만 셉니다.
부화 후에는 입력량과 관계없이 아기 24시간, 어린이 48시간을 거쳐 약 3일이면 어른이 됩니다. 게임을 꺼 둔 시간도 포함합니다.
집 창을 축소하거나 닫으면 펫이 작업표시줄 위로 산책을 나가고, 다시 열면 집으로 돌아옵니다.
작업표시줄 알림 영역의 알 아이콘을 누르면 집 창이 열리고, 우클릭 메뉴의 '끝내기'로 완전히 끕니다.

제작자의 개인 저장은 포함하지 않았습니다. 처음 받은 사람은 캐릭터를 고른 뒤 방 분위기를 선택하고, 새 알로 시작합니다.
진행은 게임 폴더와 별도로 해당 Windows 사용자 계정에 자동 저장됩니다.

방 꾸미기: 액자를 누르고 ‘방 꾸미기’에서 아늑한 원룸·귀여운 카페·숲속 오두막을 선택하세요. 벽지와 바닥은 따로 고를 수 있습니다.
‘추천 소품 미리보기’로 새 가구를 살펴보고, 필요한 동전을 확인한 뒤 ‘구매하고 적용’을 누르세요. 취소·되돌리기로는 동전을 쓰지 않습니다.

처음 시작할 때 선택한 방에 맞는 인형 1개와 동전 300개를 한 번 받습니다. 처음 도움말은 중간에 꺼도 이어서 볼 수 있습니다.
안내를 넘겼다면 집 창 위의 ‘도움말’에서 다시 볼 수 있습니다. 다시 보기나 재실행으로 선물이 중복 지급되지는 않습니다.

친구방에 접속해 있으면 20~45초 사이의 랜덤 간격으로 동전이나 재료를 자동으로 받습니다.
타이핑 보상도 함께 받을 수 있으며, 방에 접속한 동안에는 바닥에 떨어지는 연출 없이 바로 보유 수량에 들어갑니다.
방에서 나가거나 연결이 끊기면 시간 보상은 멈춥니다. 앱을 꺼 둔 시간의 보상은 쌓이지 않습니다.

다른 PC로 이동: ZIP 전체를 옮겨 압축을 푼 뒤 EXE를 실행하세요. Windows 64비트용입니다.
기존 캐릭터와 집을 이어가려면 양쪽 앱을 모두 종료한 다음, 기존 PC의 %APPDATA%\딸깍다마고치 폴더에 있는 save.json과 save.json.bak을 새 PC의 같은 위치로 복사하세요.
기존에 베타판으로 플레이했다면 원본 저장은 %APPDATA%\딸깍다마고치-베타 폴더에 있습니다. 일반판에서 이어갈 때는 대상 폴더 이름이 딸깍다마고치입니다.
받는 PC에 이미 저장이 있으면 먼저 따로 보관하세요. ZIP 자체에는 제작자의 개인 저장이 포함되어 있지 않습니다.
직접 운영하는 서버를 사용할 경우, 같은 네트워크에서는 서버 PC의 주소를 쓰고 다른 네트워크에서는 외부에서 접속 가능한 서버 주소를 사용합니다.
v0.1.2부터 기본 공용 서버 https://ddalkkak-chat.onrender.com 에 연결합니다. 별도 서버 주소를 입력하지 않고 새 방을 만들거나 초대 코드로 입장할 수 있습니다.
무료 서버가 절전 중이면 연결에 최대 90초 걸릴 수 있습니다. 서버가 재시작되면 방·초대 코드·대화는 사라져 새 방을 만들어야 합니다.
게임을 켜 둔 동안에는 5분 간격으로 공용 서버 상태를 확인합니다. 공용 방에 접속 중이면 기존 통신을 사용합니다. 게임을 완전히 종료하거나 PC를 끄거나 절전시키면 상태 확인도 멈춥니다.

v0.1.3부터 집 창 위의 ‘업데이트’를 누르면 최신 버전을 확인합니다. 새 버전이 있으면 ‘업데이트하고 다시 시작’을 누르세요.
다운로드·검증·압축 해제 후 게임이 자동으로 종료되고, 파일을 교체한 다음 다시 실행됩니다. 캐릭터·동전·집 저장은 유지되며 이전 게임 파일은 백업으로 남습니다.
파일 준비에 실패하면 현재 게임을 계속 사용할 수 있습니다. ZIP 안의 ‘딸깍다마고치’ 폴더를 그대로 사용해야 자동 교체할 수 있습니다.
v0.1.2 이하에는 이 기능이 없으므로 v0.1.3을 한 번 직접 다운로드·압축 해제해야 합니다. 그다음부터 게임 안에서 업데이트할 수 있습니다.

[0.1.4 업데이트]
게임 실행 시 새 버전을 확인하며, 집 위 업데이트에서 설치할 수 있습니다. 업데이트 내용은 최초 한 번 표시되고 업데이트 > 패치 노트에서 다시 볼 수 있습니다.
가스레인지 > 요리책에서 이상한 죽 1개로 힌트 연구를 합니다(일반10%, 특별3%). 실패해도 소모되며 이미 얻은 힌트는 중복되지 않습니다.
장난감 상자를 누르면 보유 장난감을 골라 놀 수 있습니다. 성체 편지의 나중에는 저장되며 액자 > 지금 펫 > 앞으로 함께하기에서 다시 결정합니다.
채팅방은 방 목록에서 전환하며 설정은 오른쪽 위 톱니바퀴에서 엽니다. 다시 실행하면 기억한 방의 재입장 버튼을 눌러 연결하세요. 방별 인원은12명이며 최대10개 방을 기억합니다. 작업표시줄 친구는 선택한 방 기준입니다.
키 입력500번마다 동전20개, 채팅방 접속 중40초마다 동전1개와6분마다 음식1개가 자동 지급됩니다(시간당90개·10개). 여러 방에 접속해도 중복 지급되지 않습니다.
